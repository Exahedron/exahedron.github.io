Large List of Ordinals

Intro

In set theory, ordinals are counting numbers extended to well-ordered* infinite sets. The von Neumann construction of ordinals are defined recursively: \(0\) is defined as the empty set \(\varnothing\), and each ordinal after is defined as the set of every ordinal below it. Infinite ordinals also exist, starting from \(\omega\), which contains all natural (counting) numbers.
* A set if well ordered if every subset of it has a smallest element.

I. 0 ~ ε0

This level contains ordinals that are provably well-founded using the Peano Arithmetic (PA) axioms.

  • \(0\)
    • The least ordinal.
  • \(1\)
  • \(2\)
  • \(3\)
  • \(4\)
  • \(5\)
  • \(\omega\)
    • The first transfinite ordinal.
    • It is a limit ordinal, meaning you can't reach it from adding 1 to lower ordinals.
    • Zero is not a limit ordinal because it is not the limit of any ordinal sequence.
  • \(\omega+1\)
  • \(\omega+2\)
  • \(\omega+3\)
  • \(\omega\cdot2\)
    • We've reached the second limit ordinal!
  • \(\omega\cdot2+1\)
  • \(\omega\cdot3\)
  • \(\omega\cdot4\)
  • \(\omega^2\)
    • We've reached the ωth limit ordinal, and the third additive principal number. An additive principal number is an ordinal that can't be reached from adding smaller ordinals together. The first is 1, and the second is ω.
  • \(\omega^2+1\)
  • \(\omega^2+\omega\)
  • \(\omega^2+\omega\cdot2\)
  • \(\omega^2\cdot2\)
  • \(\omega^2\cdot3\)
  • \(\omega^3\)
    • The fourth additive principal number. In general, every ordinal of the form \(\omega^\alpha\) for some \(\alpha\) is an additive principal.
  • \(\omega^3+1\)
  • \(\omega^3+\omega\)
  • \(\omega^3+\omega^2\)
  • \(\omega^3\cdot2\)
  • \(\omega^3\cdot3\)
  • \(\omega^4\)
  • \(\omega^5\)
  • \(\omega^\omega\)
    • The first ordinal that is the itself-th limit ordinal.
  • \(\omega^\omega+1\)
  • \(\omega^\omega\cdot2\)
  • \(\omega^{\omega+1}\)
  • \(\omega^{\omega+2}\)
  • \(\omega^{\omega+3}\)
  • \(\omega^{\omega\cdot2}\)
    • The second ordinal that is the itself-th limit ordinal.
  • \(\omega^{\omega\cdot3}\)
  • \(\omega^{\omega^2}\)
  • \(\omega^{\omega^2+1}\)
  • \(\omega^{\omega^2\cdot2}\)
  • \(\omega^{\omega^3}\)
  • \(\omega^{\omega^\omega}\)
  • \(\omega^{\omega^\omega+1}\)
  • \(\omega^{\omega^\omega\cdot2}\)
  • \(\omega^{\omega^{\omega+1}}\)
  • \(\omega^{\omega^{\omega\cdot2}}\)
  • \(\omega^{\omega^{\omega^2}}\)
  • \(\omega^{\omega^{\omega^\omega}}\)
  • \(\omega^{\omega^{\omega^{\omega^\omega}}}\)
  • \(\varepsilon_0\)
    • The first epsilon number! Also the limit of Primitive Sequence System and Cantor Normal Form, and the smallest ordinal that the Peano axioms can't prove as well-ordered.
    • Epsilon numbers are ordinals \(\varepsilon\) such that \(\omega^\varepsilon=\varepsilon\).
    • Buchholz's Psi: \(\psi_0(\Omega)\)
    • Sometimes called Small Cantor Ordinal
    • End of this level.

II. ε0 ~ Γ0

This level contains ordinals that are provably well-founded using Arithmetical Transfinite Recursion (ATR0).
